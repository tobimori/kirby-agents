<h1 align="center">Kirby Agents</h1>
<p align="center">
	Connect AI agents like Claude and ChatGPT to your Kirby site, and review every change before it goes live
</p>

---

## Features

- 🔌 Works with Claude, ChatGPT, Langdock and every MCP client that supports OAuth
- 🧩 Tools that know your blueprints, including blocks, layouts and structures
- 📝 Changes wait as unsaved changes in the Panel until you publish them
- 🔐 Agents log in with a Panel user and never do more than its role allows
- 🎛 Permissions per connection, which you can change or revoke in the Panel
- 🌐 [WebMCP](https://github.com/webmachinelearning/webmcp) support for agents in the browser
- 🛠 Plugins can add their own tools, permissions and field types

## Get started

[Read the documentation](docs/0_getting-started/0_quickstart.md) to get started with Kirby Agents. It requires Kirby 5 and PHP 8.2 or later.

`composer require tobimori/kirby-agents`

### What does experimental mean?

Kirby Agents is experimental. The plugin is new and is still being tested. Until version 1.0, a release can change tools, options and the classes for plugins, so read the release notes before you update.

## Contributing

Kirby Agents is open to contributors: If you open a pull request that gets merged, such as fixing a bug or translating the plugin into a new language, you're eligible for a free Kirby Agents license. Please note that I might reject minor repeat contributions or simple fixes of typos for this. Please send an email to support after your contribution has been merged.
